## 🚀 Quick Start

1. **Local Development**:
   ```bash
   npm run dev
   ```
   Access: http://localhost:3000

2. **Test Dashboard**:
   Navigate to: `/dashboard/[your-company-id]`

3. **Environment Setup**:
   Copy `.env.local` and add your API keys
